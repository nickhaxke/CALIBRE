Local DNS & Campus Network Deployment Requirements

Standard institutional network provisioning options for campus-wide or reading-room deployment.

Network Guide

Option A: Campus DNS Server + HTTPS Reverse Proxy (Recommended)

Place an institutional HTTPS reverse proxy (Nginx, IIS, or Caddy) in front of the gateway and register an internal DNS A or CNAME record pointing to the server's LAN IP:

library.institution.local. IN A 192.168.1.50 ; Reverse proxy → 127.0.0.1:8085

Option B: Reading Room Workstation hosts File

For single-workstation kiosks or isolated lab machines without a dedicated DNS server, administrators may map a friendly hostname in the system hosts file:

127.0.0.1 library.institution.local
